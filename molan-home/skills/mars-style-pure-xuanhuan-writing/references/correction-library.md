# 小说文风纠错库

本文件是《逆天重生：从废物到至尊》项目纠错库的 Skill 内置快照。通用规则适用于所有玄幻、古言文本；涉及叶辰、叶灵儿等姓名的内容只作为错误案例，不构成固定人物绑定。

优先级：用户当次手动纠正 > 当前项目规则与设定 > 本纠错库 > 一般文风偏好。用户明确纠正的表达不得在后续章节中以近义变体重复出现。

## 使用规则

1. 写作前检查“高频硬规则”和相关案例。
2. 遇到相似语境时复用纠正原则，不机械照抄示例句。
3. 完章后搜索错误写法及其近义变体。
4. 新增记录应包含章节、原句、改句、错误类型、纠正原因和纠正来源。
5. 同一案例只登记一次；用户再次确认时追加确认记录。

## 高频硬规则

| 编号 | 类别 | 必须遵守 | 常见错误 |
|---|---|---|---|
| R-01 | 物理与感官 | 声音、光线、动作遵守物理常识，不为“高级感”强行实体化 | 声音从夜色里“漏出来”、声音“飘忽不定” |
| R-02 | 动词完整 | 优先使用自然的双音节动词，不把完整动作缩成生硬单字 | “颤一下”代替“颤抖一下” |
| R-03 | 语句完整 | 主谓、宾语和必要音节完整，避免为简短而破坏汉语语感 | “哄笑一片”“力量是真实的” |
| R-04 | 修饰节制 | 删除同义重复、动作后的二次解释和无功能修饰 | “脸色一沉，又压了回去” |
| R-05 | 情绪展示 | 优先用动作、生理反应和具体细节承担情绪 | 直接写“满是心疼和无奈” |
| R-06 | 情景契合 | 每个动作、神态和情绪必须有当前情境依据 | 无开心理由却“破涕为笑” |
| R-07 | 台词力度 | 台词必须符合人物身份、处境和目标，不能只完成信息传递 | 强者受辱后只说“那是你的事” |
| R-08 | 指代清晰 | 关键动作优先使用姓名，避免亲属称谓造成视角或指代模糊 | “擦去妹妹脸上的泪水” |
| R-09 | 比喻准确 | 删除烂俗或不贴合人物状态的比喻，直接表达具体态度 | “泪如断线珠子”“语气像谈天气” |
| R-10 | 语序自然 | 避免“笑得很轻、说得很轻”等状态后置 | 改为“轻笑一声、轻声说道” |
| R-11 | 转折自然 | 根据语气强弱选择连接方式，避免机械使用“但” | 轻描淡写语境可用“只不过” |
| R-12 | 禁用AI句式 | 删除否定式煽情、全场反应模板和刻意修辞 | “不是不想说，是说不出”“所有人都愣住了” |

### 第14章派生检查

- 搜索“漏出声音、挤出声音、声音飘出”等声音实体化写法。
- 搜索“颤一下、抖一下”等拆分完整动词的表达。
- 搜索“脸色变化 + 又压回去/收回去”等二次解释。
- 搜索“笑得很轻、说得很轻、问得很轻”。
- 同一句内出现两个近义修饰词时，通常只留一个。

### 第1章派生检查

- “没”用于人物口语可以保留；叙述句默认使用“没有”。
- 不机械套用“淡淡开口”。先判断人物是克制、疲惫、敷衍还是轻蔑，再选动作和语气。
- 叶辰的反击台词要有目标和压力，但不能每次都写成预告式狠话。
- 叶灵儿的情绪变化必须经过刺激、生理反应、决定三个环节，不因一句安慰立刻转喜。
- 群体场面拆给两到三个具体人物或具体声音，不写所有人同时震惊、沉默或变色。

### 第3章派生检查

- 群像背景不自动补第二层旁观动作，一句有效议论足以建立压力时立即收住。
- 叶辰的判断不得快于物证；没有足够证据时使用“不清楚、暂时无法确定”等信息边界表达。
- 正文叙述保留“开放、完整的话、引入”等完整搭配；人物对白可以更口语。
- 打斗动作检查动词与目标的空间关系，例如布条或燃物“插进”石缝，玄力“引入”经脉。
- 伤势必须说明受伤位置和肉体后果，后文继续体现疼痛、失血或行动限制。

## 按错误类型汇总

### 物理逻辑与词语搭配

- 声音使用“传来、传出、响起”，慎用“漏出、飘出、砸下”等实体动作。
- 动作必须有身体或环境支点，不能为了画面感违反常识。
- 量词、名词和动词要能自然搭配，避开“一抹弧度”式拼接。

### 汉语节奏

- 双音节动词保持完整，如“颤抖、传出、存在”。
- 不为了短促连续省略谓语、宾语或必要虚词。
- 爆点可以收短，常规叙述保持自然长短句交替。

### 情绪与动作

- 动作已经表达情绪时，不在句尾再解释一次。
- 人物反应必须符合刚发生的事，禁止无理由转悲为喜。
- 优先写手指、呼吸、站姿、停顿和视线落点，少写抽象情绪标签。

### 对话与人物身份

- 每句重要台词都应体现人物当下诉求：反击、试探、隐瞒、控制或安慰。
- 叶辰可以克制，但不能软弱无力；强硬台词也必须建立在他掌握的信息或筹码上。
- 同一角色的口吻应稳定，不能为了推进剧情突然说出作者说明式台词。

### 去AI味

- 禁止否定式煽情：“不是X，是Y”“不是不想，而是不能”。
- 禁止统一群体反应：“所有人都愣住了”“全场死寂”。
- 删除烂俗比喻、重复修饰和刻意空间化表达。
- 避免连续使用“淡淡、平静、轻轻”等万能状态词。

## 完章速查表

| 检查项 | 通过标准 |
|---|---|
| 物理逻辑 | 声音、动作、光线和伤势符合常识及设定 |
| 动词 | 无生硬单字缩写，无重复近义修饰 |
| 语句 | 主谓与关键音节完整，段落呼吸自然 |
| 情绪 | 情绪由刺激和动作产生，无无理由突变 |
| 台词 | 符合身份、处境和目标，有人物区分度 |
| 指代 | 关键动作对象明确，必要时使用姓名 |
| 比喻 | 数量少且贴合现场，无套话比喻 |
| AI句式 | 无否定式煽情、全场反应和模板悬念句 |
| 连续性 | 改句不改变境界、伤势、时间、物品和伏笔事实 |
