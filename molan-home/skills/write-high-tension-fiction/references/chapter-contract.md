# 单章执行合同（通用）

> 原《逆天重生》专属合同已抽离为通用模板。所有占位（主角 / 视角人物 / 对手 / 力量体系 / 规则体系）按用户当前作品替换。

## 目录

1. 最小读取集
2. 章节卡
3. 场景构造
4. 设定调用
5. 节奏窗口
6. 完章记录

## 最小读取集

写第 N 章时读取：

1. `正文/第 N 章` 原稿或用户指定素材。
2. 第 N-1 章结尾和第 N+1 章开头；文件不存在时读取最近的大纲。
3. 用户项目中的 `设定总控与章节调用表.md` 第 N 行（若存在）。
4. 第 N 行要求的专项表（人物 / 物品 / 势力 / 伏笔）。
5. 出场核心角色的单体设定。
6. 用户纠错库（默认 `C:\Users\lyh\Desktop\小说\纠错库.md`）。

不要默认读取全部人物或全部势力文件。

## 章节卡

动笔前在内部确定：

- 位置：篇章、十章单元和当前场景。
- 承接：上章具体钩子。
- 主事件：一句话描述本章不可逆变化。
- 目标：视角人物此刻要取得或避免什么。
- 对抗：谁阻止，为什么不能绕开。
- 时限：具体到日、时辰、仪式、截止线或规则窗口。
- 人物：每个出场者的目标、底线和信息边界。
- 权限：哪个机构能做什么，谁在越权。
- 物品：本章为何必须使用，代价是什么。
- 伏笔：状态变化和下一次窗口。
- 回报：读者本章真正拿到什么。
- 钩子：下一章必须处理的具体压力。

## 场景构造

每章通常使用 3 至 5 场。每场明确：

1. 入场目标。
2. 阻力或误判。
3. 新信息或动作。
4. 局势变化。
5. 离场压力。

避免每场都采用“主角被嘲讽 -> 展示能力 -> 众人震惊”。替换为证据争夺、规则谈判、追逐、救援、误伤、资源取舍、关系倒戈或权限反杀。

## 设定调用

### 人物

- 让性格通过选择和代价出现。
- 主角的冷静用判断顺序体现，少写“他很平静”。
- 亲情通过资源、风险承担和具体动作表达，不反复哭诉或保证。
- 重要配角至少推进一条自己的线。

### 物品

物品使用前回答：

- 谁拥有？
- 为什么现在能用？
- 使用条件和失败风险是什么？
- 使用后改变哪项状态？
- 是否损耗、暴露或产生追踪线索？

### 组织与制度

- 把门规、法律、贡献点、考核、权限等写成角色必须应对的约束。
- 规则反杀必须引用已建立条款或提前展示的程序。
- 越权行为必须留下证据、政治代价或追责风险。

### 能力与战斗

- 明确双方能力层级和本章可用上限。
- 越级胜利至少依赖两项既有条件；跨大层级需更多条件并付出重伤、资源或暴露代价。
- 层级提升必须绑定资源、感悟、伤势或剧情选择。
- 战后更新伤势和可用能力，下一场不得自动恢复。

### 伏笔

- 新埋：给读者可感知异常，不给答案。
- 推进：新增证据或改变解释方向。
- 扭转：旧线索获得新含义，但不否定已发生事实。
- 回收：让旧线真正改变当前局面。
- 延迟：说明延迟原因和新窗口。
- 废弃：登记废弃，避免后续误用。

## 节奏窗口

- 每章至少有信息或情绪增量，并留下具体钩子。
- 约每 5 章给一次有效小回报。
- 每 10 章至少一次公开状态变化和一场身体性场景。
- 每 10 章至少推进一条非主角线和一条外部世界信息。
- 第 3 至 4 章附近设置小反转，第 6 至 7 章升级危机，第 8 至 10 章形成阶段爆点或卡点。
- 不连续两次使用“刚有进展就被更大威胁完全抹平”。

## 完章记录

按六字段回写：

| 字段 | 内容 |
|---|---|
| 人物 | 地点、能力层级、伤势、情绪、立场、关系、掌握信息 |
| 物品 | 获得、使用、损耗、转交、封存、冷却 |
| 势力 | 权限、规则触发、越权证据、公开认知 |
| 伏笔 | 新埋、推进、扭转、回收、延迟、废弃及下次窗口 |
| 结果 | 不可逆变化和读者获得感 |
| 下章 | 承接压力与必须调用的来源码 |
