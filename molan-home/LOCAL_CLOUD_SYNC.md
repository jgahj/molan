# 本地调试与云端数据同步

本地调试模式使用本地工作区的 HTML、CSS、JavaScript 和 Node 服务；账户数据与资源通过本地服务代理到云端 API。这样可以调试本地代码，同时在本地和公网页面看到同一账户的云端数据。

## 已同步的数据

- 账户资料、头像、默认模型和积分
- 小说正文、章节、设定和编辑器状态
- 个人 Skill、开放 Skill 及下载关系
- 拆书任务、拆书结果和创书相关数据
- AI 使用记录及任务状态

浏览器的主题、布局和离线缓存仍属于本地调试状态，不会被上传为项目代码，也不会触发 Git 同步。

## 启用方式

`data/config.json` 中的 `cloudApiBase` 已配置为云端服务地址。重启本地服务后，打开 `http://localhost:3000`，使用云端账户登录即可。

也可以用环境变量临时覆盖配置：

```powershell
$env:MOLAN_CLOUD_API_BASE = 'http://8.138.128.184:3000'
node server.js
```

环境变量优先于 `data/config.json`。配置为空或删除后重启服务，即恢复纯本地数据模式。

## 同步规则

- 本地服务只代理 `/api/*` 请求；静态文件始终从本地工作区读取。
- 登录、读取和保存都使用云端账户，因此不复制整份数据库到本地。
- 小说保存继续使用云端修订号，发现其他设备更新时提示处理冲突，不静默覆盖。
- 浏览器本地缓存仅用于即时显示和离线保留；成功登录并连接云端后，以云端资源为准。
- 不执行 `git pull`、不自动修改工作区、不自动部署服务器。

## 检查连接

访问 `/api/local-sync/status` 可查看当前是 `cloud-proxy` 还是 `local` 模式。访问 `/api/health` 可检查云端数据库是否正常。
