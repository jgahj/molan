# 月圆夜前的布局

罗祖云山界西境，黑岩魔窟前。

守门大圣握着骨矛，看了看张若尘，又看了看他身旁的木灵希，脸上渐渐多出几分不耐。

“没有云琉神殿的令牌，谁都不能进去。”

张若尘负手问道：“你认不认识我？”

守门大圣皱起眉头：“这里每日来往修士众多，我为何要认识你？”

张若尘向前迈步，直接越过石碑。

“连我俗世神话张若尘都不知道，找死！”

魔窟前的阵纹顿时亮起，数十道魔气从岩壁射出。木灵希早有准备，挥袖卷走附近几名修为较弱的修士，免得他们被阵法误伤。

张若尘没有取剑，只用空间力量扭曲阵纹。袭来的魔气偏离方向，接连击中崖壁，碎石落了一地。

守门大圣提矛冲上来，张若尘侧身避过，顺手夺走他腰间令牌。整个过程没有伤人，更没有碰魔窟中的一株圣药。

半刻钟后，坐镇此地的神灵被惊动。

那尊神灵刚从黑云中显化神躯，一道血色神光便从远处赶来。姑射静站到张若尘和神灵之间，抬手挡住压下来的神威。

“他由我带回去。”她说道。

神灵认得天阁目，也听说过地姥的那道指婚口谕。沉默片刻后，他收回神威，只让姑射静给一个交代。

姑射静转身看向张若尘。

张若尘将令牌抛还给守门大圣，神色坦然：“地姥欲将天阁目嫁给我，我提前巡视一下罗祖云山界，应该不算过分吧？”

守门大圣险些没有接稳令牌。

那尊神灵也多看了张若尘两眼，最终只道：“既然是地姥的意思，此事便到此为止。”

姑射静袖中的手已经握住剑柄。

离开魔窟后，她冷声问道：“这句话，你还打算说多少遍？”

“遇上不认识我的，自然要多说几次。”

“老祖宗只是赐下口谕，何时定了婚期？”

张若尘认真想了想：“所以我说的是‘欲将’，并未说已经嫁了。天阁目若觉得吃亏，也可以当众澄清。”

姑射静停下脚步。她当然可以澄清，可只要她亲自开口，此事就会传得更快。张若尘显然算准了这一点。

接下来数日，张若尘带着木灵希游遍数座神山。

有人拦路，他先报姓名；有人呵斥，他便提地姥和婚事。张若尘闯过炼器谷，登过封禁多年的祭台，还在一座神殿门前逼着两位半神辨认他的画像。

他惹出的动静不小，做事却始终留着分寸。宝物一件没有拿，修士一个没有杀，遇上真正无法收场的神威，姑射静总会赶来将他带走。

到了第五日，已有伪神主动设宴，请张若尘赴席。

酒过三巡，那位伪神端着酒杯说道：“若尘兄弟乃十界之战胜者，又与天阁目有此缘分。将来同在罗祖云山界行走，还请多多照应。”

另两位伪神跟着举杯，言语间已有结拜之意。

张若尘来者不拒，却只喝酒，不应承任何事情。宴席结束后，那三位伪神仍旧满脸喜色，仿佛已经攀上地姥这棵大树。

自那以后，他每到一处，负责镇守的修士都会提前打开阵门。偶尔有神灵察觉他的气息，也只让座下弟子送来几坛好酒，不肯亲自露面。

整个罗祖云山界，竟开始避着他走。

云琉神殿中，姑射静将一只玉杯重重放在案上。

“母神，再这样下去，外面真要把我当成他的未婚妻了。昨日还有人将贺礼送进神殿，连孩子的护身玉都备好了。”

姑射云琉翻阅着一卷神文，没有抬头。

“以你的心境，本不该被这些闲言激怒。张若尘若真想借地姥的威势捞取好处，为何没有取走任何宝物？”

姑射静沉默下来。

这几日她一直追着张若尘收拾残局，气怒之下，确实忽略了这一点。张若尘每次闯祸，都会主动报出身份，还会故意把事情闹到神灵面前。

姑射云琉合上神卷：“他在逼你厌恶他，也在逼我出面。事情闹得越大，我们越可能请求老祖宗收回口谕。”

“他利用我给他救火？”

“你若不去，那些神灵忌惮老祖宗，也未必真会杀他。你每次赶到，反倒替他坐实了传言。”

姑射静脸色冷了几分。她自认心思敏锐，这一次却被张若尘牵着走了好几日。

“母神可会向老祖宗提退婚之事？”

“老祖宗说一不二。除非张若尘做出触及底线之事，否则谁去都没有用。”

姑射静起身，取出《神储卷》。卷面铺开，一个个古老名字浮现出来，她的名字位于最前列，代表这一元会最有资格踏入神境的几人。

“那便不提了。”

姑射云琉抬头看她。

“月圆之夜，我渡神劫。”姑射静收起《神储卷》，“等我成神，再亲手收拾他。”

当天傍晚，张若尘主动来到云琉神殿。

姑射静没有让他入殿，只在山门外相见。她看着张若尘取出一块魔气深沉的石刻，原本准备好的逐客之言停在嘴边。

《天魔石刻》。

其中一幅，正是《天魔贪狼图》。

石刻上的贪狼立于残月之下，魔纹与天地规则交缠。姑射静修炼的功法与此图颇有渊源，若能在渡劫前参悟一遍，至少能补足两处尚未圆满的缺陷。

“借我？”她问道。

“月圆夜之前，都归你参悟。”

张若尘又取出日晷，神石嵌入凹槽后，古老的时间力量覆盖山门一角。

“日晷也留在这里。外界数日，足够你在日晷下修炼很久。”

姑射静没有立即接下石刻：“你又想让我替你做什么？”

“暂时没有。”

“你会如此好心？”

张若尘看着她：“你若渡劫失败，地姥或许会把这笔账算在我头上。我只是在减少麻烦。”

这话仍旧刺耳，却比那些虚伪祝愿可信。姑射静接过《天魔石刻》，手掌触及冰冷石面后，语气稍缓。

“借石刻的人情，我会还。婚事归婚事，别指望我因此信你。”

“这就够了。”

张若尘转身离开。姑射静看着他的背影，心中仍有疑虑。一个只想逼迫地姥取消婚事的人，没有必要拿出《天魔贪狼图》，更没有必要耗费神石开启日晷。

张若尘还藏着别的目的。

山外，木灵希已经等候多时。

两人沿着石阶走入林中，直到云琉神殿的阵法光辉被群山挡住，木灵希才开口：“姑射云琉多半已经看出你在故意惹事。退婚这一招，未必有用。”

“本来就没有指望她们能说动地姥。”

木灵希转头看他：“那你这几日折腾什么？”

张若尘停在一棵枯树旁，将沿途收集的请帖逐一取出。魔窟神灵、祭台守护者、炼器谷主，还有赴宴的三位伪神，几乎覆盖了这片区域的各方势力。

“我进罗祖云山界时，认得我的神灵没有几个。如今他们都知道张若尘来了，也知道我行事张扬，身后还牵扯着地姥和天阁目的婚事。”

木灵希很快明白过来：“所以你不抢宝，不杀人，每次还主动报名，就是要让他们记住你。”

“月圆夜，姑射静渡劫，诸神的注意都会集中到云琉神殿。我会离开她们的视线，去见蚩刑天。”

张若尘收起请帖，继续向前。

“途中若被神念察觉，对方认出我，便会顾忌地姥，也会以为我又在借婚事胡闹。只要没有人立刻下杀手，我就有脱身的机会。”

木灵希这才意识到，逼迫退婚只是摆在明面上的解释。连姑射云琉看破的，也只是第一层。

“见过蚩刑天以后呢？”

张若尘取出一枚没有刻字的黑色骨片。那是今晨有人放在他房门外的，背面只有一道弯月刻痕，与约定的地点有关。

“无论谈成与否，月圆夜第二天必须离开。”

木灵希接过骨片，看见弯月下方多出了一道极细的新痕。她早上查看时，那里分明还是空的。

有人刚刚改了约见之地。

张若尘抬头看向前方。林间岔路旁，摆着一只盛满酒的黑陶碗，酒面映着尚未圆满的月亮。
