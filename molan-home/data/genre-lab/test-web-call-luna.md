# 月圆夜前的布局

罗祖云山界最近很不太平。

准确地说，是张若尘走到哪里，哪里便不太平。

他带着木灵希横穿数座魔山，身边没有神将护卫，也没有刻意遮掩气息。遇见修士便拦路询问，遇见魔窟便抬脚闯入，遇见不长眼的凶兽便顺手拍飞。

“你认识我吗？”

一名大圣刚从魔窟中爬出来，迎面便看见张若尘。

他迟疑道：“阁下是……”

张若尘抬手按住他的肩膀，声音震得山壁上的碎石簌簌落下。

“连我俗世神话张若尘都不知道，找死！”

那名大圣脸色发白，连忙后退：“认识！早就听过您的大名！”

张若尘这才收手，取走他身后的灵药，又补了一句：“灵药留下，命可以保住。”

木灵希站在旁边，看着那名大圣仓皇逃走，低声道：“你说过不抢宝。”

“我拿的是赔礼。”

“他同意了吗？”

“他跑得那么快，便是不想欠我人情。”

木灵希抿了抿嘴，没有拆穿他。

接下来的几日，张若尘做得更加过分。他闯进一座魔窟，打断了几位伪神的闭关；又在山城酒楼中拍桌，询问在座修士是否听过俗世神话的名号。

有人答得慢了些，他便将酒桌掀翻。

他始终没有杀人，也没有真正抢走重要宝物。可那些修士逃回去后，添油加醋一番，传闻很快变成了另一副模样。

俗世神话张若尘现身罗祖云山界，目中无人，连伪神都敢挑衅。

更麻烦的是，他每次闹事之后，都会主动报出身份。

于是，消息传进了云琉神殿。

姑射静赶到时，张若尘正被三尊神灵围在一片黑色峡谷中。峡谷上方悬着魔云，三件神器封住了四周退路，张若尘身上的衣袍破了两处，手里却还拎着一只被打晕的魔兽。

“张若尘，把魔兽放下。”姑射静站在峡谷入口，语气冷得很，“随我回去。”

张若尘看了她一眼，抬手将魔兽丢到地上。

“你来得正好。他们三位说要请我去喝茶。”

一名神灵沉声道：“他闯我族禁地，毁去祭坛，还打伤守山神兽。天阁目，你要替他担保？”

“我只负责把他带走。”

姑射静抬手，神光铺开，挡住三件神器。

她没有与神灵正面厮杀，只将封锁峡谷的力量引向两侧山壁。轰鸣声中，黑石崩裂，三尊神灵各自收回神器，谁也没有继续追击。

地姥的威望压在罗祖云山界上方，姑射静又是天阁目。没有谁愿意为了一个闹事的张若尘，把事情闹到无法收场。

张若尘趁机走到她身边。

“多谢救命之恩。”

“闭嘴。”

“你来得这样快，莫非一直在关注我？”

姑射静抬手抓住他的衣领，声音压得很低：“再多说一句，我先把你送回云琉神殿，再亲自打断你的腿。”

张若尘顺着她的力道往前走，竟然没有反抗。

当天夜里，新的流言传遍山界。

“地姥欲将天阁目嫁给我。”

张若尘在酒楼中说得理直气壮，甚至当着几位伪神的面拍了拍胸口。

“这门婚事，乃老祖宗亲口定下。诸位以后见到我，称一声姑爷便好。”

木灵希正在饮茶，听见这句话，手里的杯子停在半空。

第二日，罗祖云山界的态度发生了变化。

一位伪神摆下宴席，拉着张若尘当场结拜，称他为兄长；另一位伪神送来珍藏多年的神酒，话里话外都在试探婚期。更多修士见到他便绕路，宁愿撞进妖兽巢穴，也不愿与这位未来姑爷擦肩。

张若尘照收不误，却始终没有应下任何实质承诺。

有人问起婚事，他便说：“老祖宗的意思，你们去问老祖宗。”

这句话传到姑射静耳中，几乎让她立刻去了云琉神殿。

“母神，他在败坏我的名声。”

姑射云琉端坐在神殿深处，手边摊着一卷《神储卷》。卷中神纹自行流转，映出姑射静这些年修行的痕迹。

“名声若靠几句话便能败坏，也不值得你在意。”

姑射静把张若尘在外面的所作所为说了一遍，越说越气：“他分明是在借地姥的名头行事。”

“他是想让地姥取消婚事。”

姑射静一怔。

姑射云琉指尖划过《神储卷》，卷中一道神纹亮起，随后归于平静。

“他故意闹事，故意报出身份，故意让诸神知道他与地姥有关系。你出面救他，便成了替他收拾残局的人。长此下去，地姥若顾及颜面，最直接的办法便是收回指婚口谕。”

姑射静沉默片刻，脸色沉了下来。

“所以，我被他利用了。”

“你现在才看出来？”

姑射静没有回答。

她确实被利用了，可张若尘也没有杀人夺宝。每次冲突，他留下的伤势都避开要害；他拿走的东西，也都是对方主动献出的赔礼。那些细节当时不显眼，放在一起，却说明他并不是真想把罗祖云山界搅烂。

这让她更恼火。

三日后，姑射静向地姥求见。

老祖宗没有解释，只传下一句话：

“口谕已出，不改。”

姑射静从地姥殿中走出，抬头看了看逐渐圆满的月轮。

她决定在月圆夜冲击神境。

等她成神，第一件事便是把张若尘丢进神殿地牢，让他把那些结拜、送礼和婚事传闻一一解释清楚。

张若尘得知此事后，主动来找她。

姑射静正在闭关之地外整理神纹，见他出现，立刻问道：“你又想闯什么地方？”

“送你一件东西。”

张若尘取出《天魔石刻》。

石刻落地，周围魔气随之沉下。其上刻着无数古老图纹，最醒目的那一幅，正是《天魔贪狼图》。贪狼伏于星海之间，獠牙咬住一轮残月，图中每一道纹路都牵动着天地规则。

姑射静看了许久，伸手触碰石刻，却没有立即收下。

“你会这样好心？”

“你若渡劫失败，我还得继续被你追杀。为了我的安全，借你观悟几日。”

“说得真动听。”

她仍然接过石刻。

张若尘又取出日晷，安置在闭关台中央。

“日晷开启后，内部流速会改变。外界一日，里面可供你观悟数年。只不过消耗极大，月圆夜之前，日晷只能开一次。”

姑射静看着日晷，没有立刻落座：“你把这种东西交给我，不怕我成神后反过来收拾你？”

“怕，所以我会坐在外面看着。”

姑射静抬手便要把石刻砸向他，张若尘却已经退到石阶下。

她忍了片刻，盘膝坐下。

日晷转动，光影从她身上掠过。《天魔贪狼图》的星纹逐渐映入她识海，她原本混乱的神境壁垒开始出现清晰脉络。《神储卷》曾记录过她的天资，可天资只是起点，真正让她看见突破方向的，是张若尘借来的天魔道痕。

两个时辰后，姑射静收功起身。

她看着石阶下的张若尘：“东西我会还你。”

“你若愿意，也可以多观悟几日。”

“我不欠你人情。”

“那便记在婚事账上。”

姑射静抬手，一道神光擦着他的耳边飞过，击碎后方石壁。

张若尘侧身避开，神色依旧平稳。

她没有再出手，却把《天魔石刻》收进了储物空间。

夜色更深时，木灵希在山脚找到张若尘。

“你今天没有抢东西，也没有挑衅谁。”她打量着他，“终于想通了？”

“我一直都想得很清楚。”

张若尘望着远处逐渐圆满的月亮，声音低了下来。

“我高调游历，是要让整个罗祖云山界的神灵都认清我的脸。月圆夜那天，我要去见一个人。”

“蚩刑天？”

木灵希没有惊讶。张若尘既然敢在魔道地界闹出这么大动静，必然有更重要的目的。

“嗯。蚩刑天藏在罗祖云山界，具体位置还不清楚。若我一直隐藏身份，月圆夜进山后，谁都可能把我当成陌生闯入者。现在不同，神灵忌惮地姥，也知道我与姑射静的婚事传闻。只要有人认出我，出手便会多几分顾虑。”

木灵希皱眉：“你把自己摆到台面上，就不怕有人故意借机设局？”

“所以我没有杀人，也没有抢走真正重要的东西。他们可以恨我，却很难拿出必须围杀我的理由。”

他说到这里，收起笑意。

“月圆夜第二天，我必须离开罗祖云山界。”

木灵希看着他：“若蚩刑天没有现身呢？”

“那就按原路离开。”

“若有人封锁出口？”

张若尘抬头看向云琉神殿的方向。

“姑射静月圆夜渡劫，云琉神殿必会牵动大半力量。那时，是最好的机会。”

木灵希还要再问，远处忽然传来一声钟鸣。

云琉神殿上空，月华凝成一道神门。姑射静闭关之地的封印正在开启，地面浮现出一行陌生的黑色魔纹，纹路尽头，赫然指向罗祖云山界最深处。

张若尘脸上的笑意消失了。

那是《天魔贪狼图》中，从未出现过的第十三颗星。
