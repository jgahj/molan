# 第一章　空窍如渊，元石知味

青溪寨建在群山断脊之间。

入夜以后，山风沿着石壁下压，吹得竹楼外的铜铃断断续续。更远处，赤焰河横过黑暗，河面映着月华，细碎的光被水流拖向下游，映得山寨护墙上的符纹时明时暗。

竹楼二层，沉砚盘坐在青石蒲团上。

蒲团边缘已经磨平，膝下竹席也受了潮，带着霉味。灶房那边有人煎药，焦葱和苦根混在一起，从楼板缝里透上来。窗沿停着一只冻僵的灰羽水鸟，啄了几下残留的油渍，羽毛沾湿，扑腾两次才飞走。

沉砚闭着眼，将意识沉入空窍。

空窍呈灰白色，四壁粗糙，布满细密裂纹。元海占据空窍下方，海面仅到窍壁中段，约有三成六分。白银真元沉重，凝滞，颜色近于浑浊的乳白，其中夹着几缕未曾炼化干净的血气，随着海潮缓慢转动。

这是他苦修三日后的积蓄。

三日前，白银真元尚余四成一分。催动一转中阶的月纹蛊，耗去七分；温养本命蛊又用了两分；昨日替族中修补竹墙阵纹，来回运转真元，折损三分。剩余的元海经过睡眠恢复，才勉强回到三成六分。

若继续修行半个时辰，元海会跌到三成以下。

三成是一个危险界线。

真元不足时，空窍壁垒会失去滋养，裂缝扩大。温养蛊虫也会受到牵连，轻则蛊虫饥饿，催动时迟滞，重则蛊虫反噬宿主。沉砚曾见过一名旁支少年为了强催火线蛊，将元海耗至两成，火线蛊在窍内躁动，烧穿三处窍壁。那少年养了半年，最后仍被族中送去外堡做杂役，领取的赔偿只有四块下品元石。

家族的账向来算得很清楚。

赔偿四块元石，是死是活，都归入“意外耗损”。

沉砚意念一动，元海中央浮出一只青铜色蛊虫。

它只有拇指大小，身体呈椭圆形，背甲上布着三道暗青纹路，腹部缓慢收缩。那是他的本命蛊，青纹食气蛊，一转高阶，能够吞食天地游离元气，转化为精纯真元，适合长期积累。

可它也挑食。

每日需要喂食两斤新鲜兽肉，肉质必须带有活性，放置超过半日，血气散尽，青纹食气蛊便会拒食。若以冻肉替代，三次之后，蛊虫会吐出腐酸，反噬宿主的经脉。

沉砚买不起每日的新鲜肉。

他通常在夜里去后山猎取山兔，再用盐石处理。山兔的血气尚在，能勉强供青纹食气蛊食用一日。若遇到雨季，猎物腐坏得快，盐石又要另算。每十斤粗盐能换三块下品元石，去掉杂质以后只剩八斤半；宗门商铺出售的精盐成色更好，一斤却要半块元石。

元石成色决定真元含量。

下品元石中，八成以上为可吸收元气，剩下是矿渣与浊气。成色九成的元石，价格通常高出两成，消耗时却少留下许多残渣。普通修士拿到元石便直接吸收，往往只看数量。沉砚会先用元气筛盘将浊气剥离，再将剩余部分分成数份，避免单次吞纳过多，冲坏空窍。

这样的筛选，会折损元石原本约一成的重量。

他从来不将损耗写在账面之外。

沉砚收回意识，伸手推开床头暗格。

暗格藏在床板第二道横木后，木轴已经松动，抽出来时发出细微的摩擦声。里面铺着一层旧麻布，麻布上堆着元石。

十三块半。

其中八块色泽清白，光面完整，边缘只留下矿脉切割时的浅痕。这八块是年终考核津贴，按照乙等下品修士的定额发放，每块成色约在八成七左右。

三块边角磨损，表面沾有灰黑色细纹，是他从坊市低价收来的残次品。卖家声称成色七成，实际只有六成半，吸收时会额外混入浊气。两块被切开过，大小不足标准元石的七成，沉砚把它们合在一起，记作半块。

另有两块元石晶莹透亮，呈淡青色。

这是甲等考核者才能领取的奖励。

沉砚用一张旧账纸包着它们，暂时没有吸收。精纯元石对空窍壁垒的滋养效果高出普通下品元石近四成，若在冲击瓶颈时使用，能少去两日调息时间。眼下用掉，等于拿将来的进境填补今日的空缺。

家族账房每年发放津贴，明面规则写得十分好看。

年终考核分甲、乙、丙三等。甲等五块上品奖励？那是长老亲传与嫡系子弟的待遇。普通一转修士若取得乙等，可得八块下品元石；丙等四块；若考核不合格，只有两块，并且要承担下一年的杂役差额。

沉砚去年被评为乙等。

账房发给他的元石只有七块。

少掉的一块，名目是“考核场地修缮费”。

族中管事解释，那年冬日霜冻，考场石台开裂，修缮耗用了不少材料。旁支少年闹过几次，最后每人又被扣去半块，名目改成“争执扰乱秩序罚金”。

沉砚没有争。

争执需要证据，证据需要证人，证人需要分利。

若只是为了追回半块元石，至少要拿出一块元石打点账房执事，再欠两个人情。收益与成本相抵，剩下的麻烦还会落在自己身上。

那次他只记下了名字。

青溪赤桑，外务堂账房执事。

今年年终考核，赤桑仍负责发放元石。

沉砚把十三块半元石重新排列，手指掠过每一块的边缘，确认没有被人动过。最后，他将两块青色元石移到暗格最深处，再放回麻布和木板。

楼梯传来脚步声。

脚步拖得很重，踩在竹板上时没有收力。三个人。

最前面的人气息虚浮，胸口呼吸略快，修为是一转中阶。后面两人真元未稳，走路时脚跟落地，显然没有经过真正的厮杀。

沉砚端坐在蒲团上，伸手将床板压实。

来人推门。

青溪赤骁站在门口，身披灰色短袍，腰间挂着一枚月纹玉牌。他身材宽厚，左手一直按着右腕，那里戴着一只精铁护腕，边缘有新的磕痕。

他身后跟着青溪石胆和青溪青芥。

“还在修行？”赤骁扫了房间一眼，“明日族内切磋，你应当知道规矩。”

沉砚看着他：“知道。”

“知道就好。”赤骁走进屋，脚下踩住一块被风吹进来的竹叶，“族中最近查得严，切磋不能伤人。你若把名额让出来，我替你担保，考核时给你报一个丙等。”

“名额是按修为与抽签决定。”

“规矩是死的，人会变。”赤骁在沉砚对面坐下，伸手拂去肩头的竹屑，“你资质普通，拿着名额也没有用。交十二块元石，这件事便算过去。”

十二块。

沉砚的资产只有十三块半。赤骁显然知道得很清楚。

能把数量报到这个程度，说明暗格位置、元石数量，甚至两块青色元石的存在，都已经有人摸过底。

赤骁来敲诈是假，确认情报才是真。

沉砚抬眼看了一下站在门边的石胆。石胆下意识收回脚，鞋底边缘沾着他房外的泥。泥色偏黄，带着石灰粉末，应该在外务堂后墙停留过。

外务堂有人参与。

赤骁伸出手：“十二块。”

沉砚从袖中取出四块元石，放在青石蒲团前。

元石碰撞，发出清脆声响。

“我只有四块。”

赤骁伸手便要拿。

沉砚按住其中一块，语气平稳：“要钱可以，先立切磋凭契。”

赤骁的手停在半空。

青溪寨有族规，正式切磋必须在演武场登记，由执事记录双方修为、赌注和伤损界限。私下冲突造成的损失，按斗殴处理。若双方自愿立下凭契，败者交付赌注，胜者无责。

赤骁自然不愿意登记。

他今日的目的只是试探，并未准备真正出手。

“你还跟我讲规矩？”赤骁问。

“你来拿元石，已经触碰族规。”沉砚将四块元石推近，“想拿，便登记。若不登记，我可以把你们三人的名字送去戒律堂，理由是强索修行资粮。”

石胆的手指抠住门框。

赤骁看了他一眼，随后看向沉砚：“你要怎么立凭契？”

“明日演武场，切磋三场。每场赌注四块元石，胜者取走赌注。若我输，四块归你；若你输，四块归我。你带两名跟班，我接受他们轮流上场。族规允许一人连战三场，伤损界限定在轻伤。”

赤骁没有立即答应。

沉砚知道他在算。

赤骁是一转中阶，真元比他深厚，催动一转中阶的石肤蛊，可以短时间承受月纹蛊的攻击。石胆修炼土道，蛊虫偏向防御；青芥速度快，但修为只有一转初阶。

三人轮流上场，赤骁有六成把握赢两场。

可若登记，他必须拿出十二块元石做赌注。赤骁拿不出。

沉砚从桌下取出一张旧账纸，在上面写下四块元石的赌注，又补了一行。

“若你们无法缴纳赌注，可以用本月外务堂的采集额度抵押。以一枚月兰花花瓣、一斤青鳞蟒肉、三份赤铁砂折算一块元石。”

石胆脸色变了。

他们三人这几日接的，正是后山采集任务。青鳞蟒肉最难取得，赤铁砂还要交回外务堂。若把额度拿出来，完成任务后便几乎没有剩余。

赤骁的手指缓慢敲着膝盖。

沉砚继续道：“当然，你也可以不赌。你们来我房中，索取十二块元石，我会照实写进戒律堂供词。你们两人站在门内，听见了全部内容。账房执事若想撇清关系，便要先解释为何提前知道我有十三块半元石。”

赤骁的敲击停住。

房外铜铃又响，风把窗缝里的灰尘吹到桌面。沉砚伸手将旧账纸压住，纸角沾着一点干掉的墨。

他心里已经算完。

四块元石是诱饵。

真正的收益来自赤骁身后的外务堂。一旦他们接受抵押，沉砚便能以切磋获胜为由，合法取得采集额度，再转手给其他旁支修士。若三场全胜，还能把赤骁与账房之间的勾连写入供词。戒律堂未必会重罚，但赤桑至少要付出一笔元石堵住这件事。

若他输掉两场，损失八块元石。

这个结果也能接受。赤骁需要在场面上证明自己强过一个旁支，才会放松戒心。沉砚只需保留最后一场，把赤骁逼到不得不亲自下场的位置。

“你早就想好了？”赤骁问。

“你们进门以前，我还没有见到凭契。”

“你以为凭这个能拿捏我？”

“我只给你两个选择。”

沉砚将笔放在账纸旁，没有催促。

赤骁沉默片刻，忽然起身，一掌拍向桌面。

木桌向内凹陷，桌角裂开。赤骁的掌力震落一只陶杯，杯子在地上滚了几圈，撞到墙脚才停下。

石胆顺势踏前半步。

沉砚身体向后退开，蒲团被鞋底带偏。赤骁的手掌擦过他肩侧，掌风掀开衣襟，露出里面缠绕的旧布。那是他早年被野狼撕伤后留下的护带，布上缝线已经发白。

赤骁没有继续追击。

这里是竹楼。

真元冲撞过重，会损坏楼体。山寨规定，损坏家产者需照价赔偿，擅自在居所动用蛊虫，还要追加半月杂役。

沉砚抬脚踢中那只陶杯。

陶杯弹起，撞在赤骁膝下。赤骁腿骨向旁一偏，脚步顿住。沉砚抓住桌角，将裂开的木桌推向石胆，木板横扫过去，石胆抬臂挡住，门框立刻发出沉闷的碎裂声。

“损坏竹楼一处门框，一张桌。”沉砚说，“你们三人承担。”

赤骁压住怒意，伸手将石胆拦下。

沉砚从蒲团旁捡起一枚竹牌。竹牌是房屋登记凭证，正面有居住者姓名，背面刻着修缮价格。门框三块元石，桌面两块，合计五块。

“你若动用蛊虫，价格翻倍。”他把竹牌放到桌上，“赌注从十二块增加到十七块。你们若拿不出来，我现在便去叫人。”

“你在敲诈我。”赤骁说。

“族规记的是损坏数额。”

赤骁看着那枚竹牌，胸口起伏了两次。

楼下传来卖炭人的吆喝，声音被风吹散，只有几个字落进竹楼。街边的油灯烧尽了灯芯，摊主弯腰添油，手背沾了一层黑灰。

赤骁最终没有继续出手。

他从怀中取出一枚外务堂铁牌，拍在桌上：“明日演武场，三场切磋。你若输了，四块元石，加上修缮费。你若赢了，凭契作废。”

沉砚拿起铁牌，用指甲刮过边缘。

铁牌背面刻着外务堂的月纹，刻痕很新，牌身却有潮气。它刚从后墙的登记柜中取出，尚未经过执事盖印。

“这不是正式凭契。”

赤骁脸上终于出现变化。

沉砚将铁牌推回去：“让青溪赤桑盖印。再加一句，赌注由三场总计十二块，改为每场四块。修缮费另算，胜负后当场结清。”

赤骁没有伸手。

沉砚拿出一块成色最差的元石，用指节敲了敲桌面：“你今日若空手离开，便等于承认只是来试探。试探的消息传回外务堂，赤桑会先把你推出去。若立了凭契，你至少能把事情包装成正常切磋。”

这句话击中了赤骁真正的软处。

长辈不会保护一个办砸差事、还留下把柄的晚辈。赤桑借他们试探旁支资产，事成之后可以分利；事情败露，最先承担责任的也会是他们三人。

赤骁拿回铁牌。

“明日见。”

“带足元石。”

赤骁转身离开。石胆经过门口时，目光在那四块元石上停了一下。沉砚将它们收入袖中，动作很慢，四块元石一枚不少地收好。

青芥离开前，脚下踩碎了那片竹叶。

三人的脚步沿楼梯向下，逐渐被街巷的杂音盖住。

沉砚关上门，重新扶正蒲团。

他没有立即修行。

先检查门框裂痕，再将碎陶片扫入簸箕。那张旧账纸被风吹到地上，墨迹尚未干，他将纸折好，压在床板下面。

今夜必须补充青纹食气蛊的食物。

后山距离山寨不近，若空手而去，往返会耗费两成真元。沉砚在暗格里取出半块残次元石，握在掌心，运转吸纳法。浊气先进入经脉，令气息短暂滞涩，随后才有稀薄元气流入空窍。

半块元石耗尽，元海只涨了一分。

残渣落在掌心，呈灰黑粉末。沉砚将它装进小纸包，明日可以拿去换盐，卖不出价，却能抵半斤粗盐。

他重新坐下，意识沉入空窍。

青纹食气蛊在元海上方缓慢爬行，腹部发出细微摩擦声，显然已经饥饿。沉砚催动真元，将三成六分的元海抽出两分，送入蛊虫体内。

元海下降，海面露出空窍底部一块灰白石壁。

青纹食气蛊吞食真元后，背甲上的暗青纹路逐渐明亮，随后吐出一团稀薄元气。那团元气比原本精纯，回流时却只剩一分半。

温养一次，损耗半分。

沉砚记下这个数。

若明日三场切磋，他至少要保持两成五分真元，否则第二场便无法催动月纹蛊。赤骁的石肤蛊持续时间不会超过一炷香，石胆行动迟缓，青芥防御薄弱。先取青芥，再逼石胆用掉护体真元，最后留下赤骁。

这场切磋能赢。

赢得不多，却能获得外务堂额度、五块修缮费，还能让赤桑多付出一笔封口钱。

沉砚睁开眼，窗外山月已经偏西。

床板下，旧账纸压着一行尚未干透的字：

青溪赤桑，扣发津贴一块；考场修缮费，无据；外务额度，疑有私分。

他将纸重新压紧，起身取弓。

青石蒲团留下一圈浅灰尘印。

元石知道味道，家族也知道。

沉砚推门下楼，肩上背着旧弓，腰间挂着短刃。门框裂缝在风里轻轻碰撞，发出木料相互挤压的声音。山寨外的护墙符纹已经暗了三成，守夜弟子正往阵盘里填入碎元石，动作匆忙，生怕多消耗半块完整矿料。

沉砚从他们身边经过，没有停步。

后山的黑暗压在石阶尽头。

青纹食气蛊在空窍中缓慢游动，等待新鲜血肉。明日的凭契也在等待落印。

他走入山风里。
