# 月圆夜前的布局

罗祖云山界最近出了件怪事。

一个叫张若尘的外来修士，带着木灵希，在各座魔城之间游荡。今日砸了黑石坊的招牌，明日闯进血蝠洞，后日又在万骨山门前拦住一队押送囚徒的魔修，挨个询问：

“你们认识我吗？”

那队魔修面面相觑。

张若尘抬手指着山门，语气里带着毫不掩饰的嫌弃。

“连我俗世神话张若尘都不知道，找死！”

木灵希站在旁边，手里还拿着一串刚买来的灵果。她看了看被张若尘一掌拍塌的半面石墙，又看了看那些被吓得四散奔逃的魔修，慢慢咬了一口灵果。

“你这样闹，真能把姑射静逼出来？”

“她已经来了。”

张若尘侧过脸。

天边，一片雪白神光穿透黑云，落在万骨山上。神光里走出一道身影，白衣束发，袖口绣着云纹，正是姑射静。

她没有看张若尘，先抬手封住了即将崩塌的山门。

轰鸣声被截在半空，滚落的碎石停了一瞬，随后堆在她脚边。

被张若尘打伤的那名伪神连忙跑过去，躬身道：“天阁目，此人无故闯山，毁坏阵门，还打伤了守山神将。请您主持公道。”

姑射静终于转过身。

“张若尘，你又做了什么？”

张若尘抬起手，指了指那块歪斜的石碑。

“我问他们认不认识我，他们说不认识。”

“所以你拆了山门？”

“他们回答得不够诚恳。”

木灵希把灵果核吐进掌心，没忍住笑了一声。

姑射静的手指在袖中收紧，眼前这个人分明是故意的。可她还是得替他收拾残局。

最近三日，张若尘已经闯了七处魔道禁地，惹怒了三位神灵，欠下两场决斗，还把罗祖云山界最有名的黑市搅得一团乱。偏偏地姥提前吩咐过，张若尘在界内行走，任何人不得真正伤他性命。

这道命令给足了张若尘胡闹的本钱，也把姑射静推到了最前面。

她是天阁目，是元会级代表人物，许多神灵不敢杀张若尘，却敢把麻烦递到她手里。

“跟我走。”姑射静说。

“去哪？”

“救你。”

“我没受伤。”

“救你免于被他们围攻。”

张若尘顺着她所指看去，远处已经聚起七八道神境气息。先前那名伪神趁着姑射静与他说话，悄悄捏碎了传讯符，几位镇守万骨山的神灵正在赶来。

张若尘立刻往木灵希身后一站。

“静姑娘，他们要杀我。”

木灵希把手里的灵果塞进他怀里，自己退开两步。

“你别躲我后面。”

姑射静看了木灵希一眼，随后抬袖卷住张若尘的肩膀。空间被云光切开，她带着张若尘离开万骨山，连给那几位神灵追问的机会都没有。

落地后，姑射静松开手。

张若尘踉跄半步，整理了一下衣襟。

“多谢救命之恩。”

“闭嘴。”

“你若愿意，我可以把这件事宣扬出去，让大家知道天阁目对我有救命之恩。”

“你敢。”

“有什么不敢？我张若尘行事向来坦荡。”

姑射静转身就走。

张若尘跟在她后面，还不忘补上一句：“对了，地姥欲将天阁目嫁给我。”

姑射静的脚步停住。

木灵希手中的灵果掉在地上。

“你说什么？”姑射静缓慢转身。

张若尘却已经看向远处赶来的几名魔修，神情坦然。

“我说得不够清楚吗？地姥欲将天阁目嫁给我。你今日救我，也是提前培养夫妻情分。”

那几名魔修停在半空。

其中一位伪神张了张口，原本准备质问的话咽了回去。他们望向姑射静，又看了看张若尘，最后很有默契地转身离开。

不出半日，这句话传遍了罗祖云山界。

当晚，三名伪神亲自登门，带着灵酒与礼册，邀请张若尘赴宴。

“张兄，早听闻你是俗世神话，今日一见，果然器宇不凡。”

“张兄与天阁目乃是天作之合，往后便是一家人。”

“我等愿与张兄结拜，若日后有用得上我等的地方，只管开口。”

张若尘坐在席间，面前摆着九坛灵酒，耳边全是恭维。

他没有想到事情会发酵得如此快。

更没有想到，结拜的消息传出去后，整座魔城都开始避着他走。

他去酒楼，掌柜提前关门。

他进坊市，摊主收起灵药。

他站在街口问路，路人立刻转身，连传音都不愿与他牵扯。

这下轮到张若尘沉默了。

木灵希坐在屋檐边，笑得肩膀发颤。

“你不是很满意吗？现在整个罗祖云山界都知道你是地姥看中的孙女婿。”

“我只想让地姥觉得我不适合成婚。”

“结果你成了界内最不能得罪的人。”

张若尘端起茶盏，发现杯中早已没有茶水。

“这说明他们对我的敬畏还不够。”

木灵希收起笑容。

“你少来。你到底在算计什么？”

张若尘没有回答。

同一时间，云琉神殿。

姑射静把一枚玉简拍在案上。

“母神，您看看外面都传成什么样了？我去救他一次，便成了夫妻恩情；我替他挡三道神术，又被说成护夫心切。再这么下去，我连神殿都不敢出门。”

姑射云琉坐在神座上，手边放着一卷古老经文。她没有急着安慰女儿，只把玉简拿起来扫了一眼。

“你知道他为何如此高调吗？”

“他疯了。”

“张若尘不会因为几名伪神不认识自己，就毁掉七座魔窟。”

姑射静抿着嘴。

她当然知道张若尘不是疯子。十界之战的胜者，能从诸天万界杀出一条路的人，绝不会把力气浪费在这种地方。

可正因如此，她才更恼火。

她被张若尘一次次引出来救场，成了他计划中的一枚棋子，却连棋局的边角都没看见。

姑射云琉放下玉简。

“他在逼地姥取消婚事。”

姑射静怔住。

“地姥定下的事，从来不会因为旁人几句闲话改变。张若尘把自己塑造成惹祸精，就是想让老祖宗觉得，将你嫁给他会给罗祖云山界带来无休止的麻烦。”

姑射静想起张若尘闯入血蝠洞时的表情，想起他明明能一掌破阵，却偏偏站在洞口大喊自己的名字。

那些挑衅并非失控，每一步都踩在别人最容易动怒的地方。

“所以我这些天替他救火，全都在帮他？”

“至少目前是这样。”

姑射云琉的语气不重，却让姑射静无法反驳。

她起身走到殿外，云琉神殿下方是万丈云海，远处魔城灯火连成一线。

“我不会让他如愿。”

“你准备怎么做？”

“成神。”

姑射静回头，已经做出决定。

“老祖宗说一不二。只要我踏入神境，婚事便不再是他想推就能推的安排。等我渡劫成功，再找他算账。”

姑射云琉没有阻止。

冲击神境不是儿戏，何况姑射静已经站在伪神巅峰多年，月圆之夜又是她自行推演出的最佳时机。一旦失败，神魂受损，千年积累尽毁；一旦成功，她也要面对神境雷劫留下的道伤。

“你想清楚了？”

姑射静拿起案上的玉简。

“我只想清楚了一件事。”

她望向云海尽头。

“我不想再被他牵着走。”

月圆夜前两日，张若尘主动登上云琉神殿。

姑射静正在殿后石台上调息，见他来，抬手便要封闭石门。

“等一下。”张若尘从袖中取出一块残缺石碑，“我来送东西。”

石碑出现的刹那，周围云气突然沉下去。

姑射静看着那块石碑，神色变了。

《天魔石刻》。

罗祖云山界最重要的传承之一，据说其中刻有天魔始祖留下的道痕。普通神灵无法直接参悟，即使伪神接触，也可能被魔念侵入。

“你从哪里得到的？”

“地姥借给我的。”

“她知道你要给我？”

“知道。”

姑射静没有立即伸手。

张若尘把石碑放在石台中央，又取出日晷，调整了三枚晷针的位置。

“你冲击神境，最大的难处不在积累，而在神魂与规则的衔接。《天魔石刻》能让你看见自身规则的缺口。日晷会把外界时间压缩，给你三日观悟。”

姑射静看着他。

“你会这么好心？”

“我希望你成功。”

“我若成神，第一个收拾的人就是你。”

“那也比你渡劫失败强。”

这句话没有半点讨好，姑射静反而安静下来。

张若尘继续道：“《天魔石刻》只能使用一次，三个时辰后必须封存。日晷会消耗神石，观悟结束，你至少要休养半月。若强行渡劫，风险会更高。”

他把代价和限制都说得清楚，没有故意夸大功效，也没有要求她承诺什么。

姑射静伸手按在石碑上。

一股森冷意志立刻侵入神魂。她眼前出现无数断裂的规则线，原本已经融合的神道力量，在石刻映照下露出细微错位。

她不再理会张若尘，盘膝坐下。

日晷开始转动。

时间在石台周围变得迟缓，云海的涨落被拉成漫长的白线。张若尘守在石台旁，替她挡住几次外界神念探查，却没有插手她的领悟。

三个时辰后，姑射静睁开眼。

石刻上的魔纹少了一道，日晷也裂开了一条细痕。

她看着张若尘，神情比之前复杂许多。

“你早就看出我的规则缺口？”

“看出一点。”

“为何帮我？”

“你成神之后，至少有能力自己收拾我。”

姑射静抬手将石刻收起。

“你以为我会因为这件事放过你？”

“我没这么想。”

这一次，她没有立即反驳。

她曾以为张若尘只是为了逃婚，才故意把事情闹大。可他愿意拿出《天魔石刻》，还提前讲明日晷的损耗与反噬，说明他并不想让她真的死在神劫之下。

这个人身上的算计很多，却没有把她当成可以随意牺牲的棋子。

至少现在没有。

离开云琉神殿后，张若尘与木灵希回到暂住的山谷。

木灵希靠在树旁，等他落地便开口：“你对姑射静用了几分真心？”

“你问的是哪一件？”

“帮她观悟。”

“她若渡劫成功，对我有好处。”

“果然。”

张若尘从袖中取出一枚黑色玉符，在掌心转了转。

“我要让整个罗祖云山界知道我是谁。”

木灵希收起玩笑。

“你已经闹得人尽皆知。”

“还不够。我要让每一位神灵都清楚，张若尘在月圆夜会出现在什么地方。”

“故意把自己变成靶子？”

“靶子越亮，暗箭越不敢射。”

木灵希看着他手里的玉符。

“你要去见蚩刑天？”

张若尘点头。

蚩刑天被困在罗祖云山界深处，地姥的禁制与诸神监视层层叠加。若张若尘遮掩身份潜入，反而容易被当成外敌围杀。只有把行踪公开，让所有人都以为他在月圆夜准备渡劫、赴宴或与姑射静谈婚事，真正的路线才有机会藏在众目睽睽之下。

“月圆夜，我会去见他。”张若尘说，“第二天必须离开罗祖云山界。”

木灵希皱眉。

“如果姑射静渡劫成功，地姥仍不取消婚事呢？”

“那就更该离开。”

张若尘把玉符收入袖中。

山谷外，第一轮月光越过黑色山脊，照在日晷那道新裂纹上。

裂纹内部，忽然浮出一行细小的血字。

张若尘伸手按住日晷，血字却没有消失。

那是蚩刑天留下的传讯。

只有一句话：

**月圆夜，别来见我。**
