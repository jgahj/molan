## 一、指标评测检测模式分流分类

| 检测分类 | 指标数量 | 核心原则 | 代表指标 |
| :--- | :---: | :--- | :--- |
| **适合自动检测 (auto)** | 8 项 | 纯确定性、统计学与正则标点匹配，100% 规则可量化 | 章节长度、对话比例、心理描写、人物数量、连续平淡章节 |
| **必须联合判断 (hybrid)** | 6 项 | 规则初筛波形/频次 + LLM 校验实质文学价值 | 冲突密度、信息密度、章末钩子、爽点兑现、情绪波动 |
| **必须由 LLM 深层判断 (llm)** | 4 项 | 需跨章全局语义推演，涉及因果动机与主线推进 | 伏笔埋设隐蔽度、伏笔回收率、剧情因果密度、主线跃迁速度 |

### 1. 适合自动检测指标明细

- **章节长度** (`chapter_length` / 字)：纯字符统计与字数预算核算，规则可 100% 确定性精确量化。
  - *情境说明*：玄幻修真长篇单章通常较大 (2500-3800)，都市快节奏或对话流偏短 (1800-2600)。卷终高潮章篇幅翻倍属于合理扩容。
- **对话比例** (`dialogue_ratio` / 比率)：基于对话引号对标记的封闭性字符统计，确定性强。
  - *情境说明*：都市言情与古代宅斗对白密度高 (35%-55%)；荒野求生、单刷秘境与重工业硬科幻对白极少 (15%-25%)。独处探索章对白为零属常态。
- **心理描写比例** (`psychological_ratio` / 比率)：直接内心独白动词、心理状态指示词匹配，无模型依赖。
  - *情境说明*：闭关突破、重大人生抉择与心魔劫章节，心理自省比例显著上升；激战拼杀动作章节心理句大幅收敛。
- **描写比例** (`description_ratio` / 比率)：五感动词、感官修饰与物理受力动作段落占比。
  - *情境说明*：动作战斗章描写密集；快节奏交割交易或快速推进章以叙述和对白为主。
- **活跃人物数量** (`character_count` / 人/章)：启发式名+动词实体识别与代词过滤，规则可稳定统计。
  - *情境说明*：拍卖会、宗门大比或寿宴场景活跃人数密集 (6-12人)；潜行刺杀、闭关修炼场景仅主角 1 人。
- **平淡章节连续长度** (`consecutive_flat_chapters` / 章)：基于张力波峰与冲突标记的滑动窗口连续计数。
  - *情境说明*：日常种田、修仙日常流对平淡连续容忍度高 (2-4章)；战神反打脸或规则怪谈求生类容差极低 (<=1章)。
- **新人物登场密度** (`new_character_density` / 人/万字)：跨章实体库去重与全局首次出现位点差分统计。
  - *情境说明*：开篇 1-5 章换地图阶段新人物密集；中后期剧情收拢阶段需严格限制新人物，防止认知过载。
- **新设定密度** (`new_setting_density` / 处/万字)：专有体系词、境界、宗门、法宝术语出现频率分析。
  - *情境说明*：开篇世界观铺垫期设定集中；中后期应侧重既有规则的对抗应用，而非不断空降新体系。

### 2. 适合联合判断指标明细

- **场景数量** (`scene_count` / 个/章)：规则初筛时空指示词与空行标记，LLM 校验是否为真正物理转场而非角色回忆闪回。
  - *情境说明*：单章平均 1-3 个场景。战术追击或多线并进可达 4-5 个场景；深室盘问或单场擂台可全章单一场景。
- **冲突密度** (`conflict_density` / 段落比)：规则快速捕获对抗动作与对抗词，LLM 审计冲突是否具备实质利益阻力与尊严博弈。
  - *情境说明*：高潮大战章冲突密度超 0.70；战后清点战利品与养伤过渡章允许低于 0.20，属于必要的情绪回落。
- **信息密度** (`information_density` / 有效信息量/千字)：词汇多样性与实体分布初筛，LLM 剔除无效注水与同义复述，计算净剧情推进量。
  - *情境说明*：快穿、悬疑解密信息密度极高；传统长篇仙侠讲求节奏蓄势与氛围沉淀，信息密度适中。
- **钩子密度** (`hook_density` / 处/章)：末尾段式启发匹配初筛，LLM 最终确认是否形成有效的心流悬置与阅读驱动。
  - *情境说明*：章末必须留有悬念（新危机/反转/疑问）；章中微钩子维持注意力。分卷终章可适度闭环释放。
- **爽点密度** (`shuangdian_density` / 处/章)：反转震惊与收获词初筛，LLM 核验读者期待是否得到充分压抑后的实质释放。
  - *情境说明*：爽文流打脸密集；慢热硬核求生流追求长时间沉淀后的单次巨大复利兑现，单章爽点计数不宜盲目追求过高。
- **情绪变化频率** (`emotion_variation` / 波峰波谷/章)：情感正负极性词动态变化曲线初筛，LLM 判别情绪转变的合理性与潜台词错位。
  - *情境说明*：绝境反转章情绪由极度压抑骤转为狂喜与释怀；日常平稳章情绪波动舒缓。

### 3. 必须由 LLM 深层判断指标明细

- **伏笔埋设数量** (`foreshadow_count` / 条/章)：需要深层语义理解道具磨损、异常言行与深层因果，纯规则无法区分普通环境陈设与真正线索。
  - *情境说明*：开篇阶段每章埋设 1-3 处隐性伏笔；高潮对决阶段应主要集中收拢，少埋新长线伏笔。
- **伏笔回收率** (`foreshadow_payoff_rate` / 百分比)：需跨章节追溯因果账簿，核实前期悬置线索是否在当前情境下以合逻辑方式兑现。
  - *情境说明*：单章微伏笔当章回收；长线伏笔跨卷回收；完本或卷末回收率应趋近 100%。
- **剧情因果密度** (`causal_density` / 健全度评分)：需全局推演行动动机与连锁反应，判定事件是否为主角主观能动而非天降机械神或反派降智。
  - *情境说明*：高水平作品因果链环环相扣 ($A \to B \to C$)；任何偶发事件必须在前文有概率伏笔垫底。
- **事件推进速度** (`event_progression_speed` / 主线跃迁指数)：需审视全局剧情阶段与核心冲突目标，判断章节是在实质推演主线还是在无意义灌水。
  - *情境说明*：不同流派主线推进周期不同。快节奏文 1-2 章一换局，大架构群像文允许在支线博弈中多线编织。
