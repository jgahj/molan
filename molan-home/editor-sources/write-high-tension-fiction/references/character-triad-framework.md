# 人物人性、神性与魔性框架

## 核心原则

把人性、神性、魔性当作角色面对同一困境时的三种力量，不当作三个标签平均分配。

- **人性**负责共情：角色想活、怕失去、会偏心、会嫉妒、会后悔，也会在亲友与大义之间权衡。
- **神性**负责仰望：角色愿意为了责任、理想、悲悯、秩序或信念克制自身欲望，并承担真实牺牲。
- **魔性**负责危险：角色被执念、复仇、控制欲、自由欲或破坏欲推动，愿意走一条有效但越界的捷径。

不要求每名配角三性齐全。核心角色确定一个主导面、一个隐藏面和一个会在压力下浮现的面；重要转折至少让其中两面发生冲突。

## 落地方式

### 人性

用以下内容表现，不直接写“他很有人性”：

- 对某个人例外，对相同规则给出不同选择。
- 在资源、性命、尊严和亲情之间犹豫或偏心。
- 因恐惧隐瞒、逃避、迁怒或提前控制风险。
- 在宏大目标之外保留食物、旧物、承诺、羞耻和生活习惯。

人性必须影响决定。只补一段悲惨过去、流泪或温柔动作，却不改变选择，不算有效人性。

### 神性

神性不是境界高、气势强或台词宏大，而是角色明知代价仍守住某条高于自身利益的原则。

- 先写角色真正想保住的私人利益。
- 再让信念要求他放弃、延迟或冒险失去这项利益。
- 落实身体、关系、权力、名誉、寿命或机会成本。
- 让选择产生旁人无法轻易复制的崇高感，而不是作者宣布“伟大”。

没有代价的牺牲、必胜前提下的勇敢和顺手救人都不能单独构成神性。

### 魔性

魔性不是随机发疯、滥杀或粗暴叫嚣，而是角色拥有一条诱人、有效、符合执念，却会破坏边界的行动逻辑。

- 明确角色最不能失去什么，以及为此愿意破坏哪条规则。
- 让越界行为确实带来短期收益，读者才能理解诱惑。
- 保留角色自我辩护：他为什么认为只有自己敢做、应该做或必须做。
- 写清受害者、关系破裂、反噬和长期代价，不把“自由”包装成免除责任。

反派的人性用于解释，不用于免罪；主角的魔性用于制造真实内在风险，不用于无代价耍帅。

## 场景六问

重要人物作出选择前，在内部回答：

1. 他此刻作为普通人最想保住什么？
2. 他最怕失去谁、什么身份或哪种生活？
3. 他的信念要求他克制或牺牲什么？
4. 眼前是否存在一条更快、更狠但会越界的办法？
5. 他最终选择哪一面，为什么这一刻会这样选？
6. 该选择造成什么不可逆的身体、关系或制度后果？

正文只呈现动作、对白、犹豫和后果，不出现“这是他的人性/神性/魔性”的作者解说。

## 通用人物映射模板（按你的作品填充，不绑定任何专有作品）

| 维度 | 填写提示 |
|---|---|
| 人性 | 他最怕失去谁/什么？在资源、性命、尊严、亲情之间会如何偏心或隐瞒？ |
| 神性 | 他真正想保住的私人利益是什么？信念要求他放弃/延迟/冒险失去什么？代价落在何处？ |
| 魔性 | 他最不能失去什么，为此愿破坏哪条规则？越界带来什么短期收益与长期反噬？ |
| 核心冲突 | 三种力量在什么情境下必然冲突？选择产生什么不可逆的身体/关系/制度后果？ |

填写示例（占位，使用时替换为你的角色）：
- 主角：人性=害怕再次被背叛失去亲人；神性=愿为责任克制自身欲望并承担牺牲；魔性=复仇狠意与控制欲。冲突=守护亲人是否允许他替亲人决定一切。
- 反派：人性=仍有感情与愧疚；神性=愿为某种大局承担骂名；魔性=以结果合理化越界手段。冲突=救一方能否成为牺牲挚友的理由。

## 检查禁区

- 不给角色平均贴上三段介绍，三性通过不同章节的选择逐层显露。
- 不把哭泣、爱吃某物、照顾孩子自动当作人性。
- 不把强大、冷静、白衣、牺牲口号自动当作神性。
- 不把杀人、邪笑、黑气、喜怒无常自动当作魔性。
- 不为了反转临时增加童年创伤、特殊偏爱或崇高理想。
- 不让角色越界后只收获魅力而没有责任与后果。
