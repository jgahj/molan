# 《逆天重生：从废物到至尊》纠错库

> 来源：`agent.md` 第十一节“纠错库”。本文件已合并重复记录，作为写作前检查和完章质检的独立入口。
>
> 优先级：用户最新手动纠正 > 用户既往手动纠正 > 已确认项目规则 > AI自查建议。用户明确纠正的表达不得在后续章节中以近义变体重复出现。

## 一、使用规则

1. 写作前先检查“高频硬规则”和相关章节案例。
2. 写作中遇到相似语境，复用纠正原则，不机械照抄示例句。
3. 完章后搜索错误写法及其近义变体。
4. 新增记录必须包含：章节、原句、改句、错误类型、纠正原因、纠正来源。
5. 同一案例只登记一次；若用户再次确认，在来源栏追加确认记录。

## 二、高频硬规则

| 编号 | 类别 | 必须遵守 | 常见错误 |
|---|---|---|---|
| R-01 | 物理与感官 | 声音、光线、动作遵守物理常识，不为“高级感”强行实体化 | 声音从夜色里“漏出来”、声音“飘忽不定” |
| R-02 | 动词完整 | 优先使用自然的双音节动词，不把完整动作缩成生硬单字 | “颤一下”代替“颤抖一下” |
| R-03 | 语句完整 | 主谓、宾语和必要音节完整，避免为简短而破坏汉语语感 | “哄笑一片”“力量是真实的” |
| R-04 | 修饰节制 | 删除同义重复、动作后的二次解释和无功能修饰 | “脸色一沉，又压了回去” |
| R-05 | 情绪展示 | 优先用动作、生理反应和具体细节承担情绪 | 直接写“满是心疼和无奈” |
| R-06 | 情景契合 | 每个动作、神态和情绪必须有当前情境依据 | 无开心理由却“破涕为笑” |
| R-07 | 台词力度 | 台词必须符合人物身份、处境和目标，避免全场统一震惊模板 | 强者受辱后只说“那是你的事”，“所有人都愣住了” |
| R-08 | 指代清晰 | 关键动作优先使用姓名，线索不足只表达信息边界，不越界预判 | “擦去妹妹脸上的泪水”，单一迹象提前断定唯一真相 |
| R-09 | 比喻准确 | 删除烂俗或不贴合人物状态的比喻，好比喻四原则与删除测试 | “泪如断线珠子”“语气像谈天气” |
| R-10 | 语序自然 | 避免“笑得很轻、说得很轻”等状态后置 | 改为“轻笑一声、轻声说道” |
| R-11 | 证据因果 | 区分观察、怀疑、假设与确认，结论不得超过证据范围 | “显然就是”“一定是”“太恐怖了” |
| R-12 | 禁用AI句式 | 删除否定式煽情与机械工整推理，节制装饰性数量词 | “不是不想说，是说不出”，“一丝/一股+抽象词”泛滥 |
| R-13 | 制度解释 | 人物因规则行动前，先交代名词对象、执行方式与代价，不写百科段落 | 先说“扣三房份额”，后文才解释三房、份额与考核 |
| R-14 | 模板神态 | 严禁用“嘴角/唇角勾起一抹弧度/冷笑”等模板化神态 | “嘴角勾起一抹玩味的弧度” |
| R-15 | 句子功能 | 身体状态、转场和时间句必须新增行动限制或局势变化 | “双腿还能用”“两人赶在第三遍钟前离开柴院” |
| R-16 | 人物口吻 | 对白带出身份性格，叙述用“嘴角”不用“唇角” | 亲近人物对白机械压成冷硬短句，叙述频现“唇角” |
| R-17 | 动作主体 | 人物或持有物承担动作，不让局部物件无故独立行动 | “叶宁的笔尖顿在纸上”，“目光落在/视线投向” |
| R-18 | 声音实体化 | 声音自具体物理位置传来，严禁用从齿缝挤出或化作凝重 | “从齿缝里挤出这两个字”，“关上门化作冰冷的凝重” |
| R-19 | 旁白越权 | 旁白只写物理事实与可观察行为，不替读者下价值判断与过度惊叹 | “实在不值当”“成长速度太恐怖了”“何其骇人” |
| R-20 | 对比句式 | 清零能力展示对比句框架，让判断直接紧跟感官 | “普通人未必能分辨，主角却太熟悉/一眼看穿” |
| R-21 | 伤势具象 | 战斗伤势落到具体皮肉受损、出血与活动受限，不用抽象比喻代替实际损伤 | “像被重新凿了一遍”“像被撕裂开来” |
| R-22 | 避免微计时 | 神态反应使用直接动作，不用刻意计时营造精密感 | “嘴角的笑停了半息/一息” |
| R-23 | 时代与语境 | 用语服从故事背景，古代语境不滥用现代法务/行政黑话，现代不强行古风 | 古代写“证物链、涉案物、流程闭环、KPI、颗粒度” |
| R-24 | 拒绝脱口秀 | 删除脱离人物处境的现代段子与脱口秀感悟腔，保留真实关系幽默 | “坏事总能精准地……所谓的不过是……或许这就是……的意义” |
| R-25 | 拒绝账目复盘 | 章末落在即时后果与当面行动，禁止章尾账目盘点式机械复盘 | “他损了多少、赔了多少重铠法器银两” |
| R-26 | 段落呼吸 | 短段、拟声独立成段与心理停顿结合上下文，不设置机械句数配额 | 为迎合检测分数机械合并短段或为凑句数强行扩写 |
| R-27 | 拒绝回合制 | 多人群殴必须写出泥泞混乱合围感，严禁领号报数排队单挑 | “最前一人……第二名……第三名……第四名……拔刀” |
| R-28 | 破除二元对称 | 语法自然质朴，严禁机械二元工整对仗句式 | “一枚……一枚……后者……”、“第一步……第二步……” |
| R-29 | 拒绝口号复读 | 配角对白体现真实惊惶算计与市井油滑，禁止像喇叭般重复播报口号 | “别见血！”“老子护账不护脑袋！”复读 |
| R-30 | 拒绝招式报幕 | 战斗叙事中禁止突然蹦出游戏技能名与图鉴说明 | 突然蹦出“杀步。”或“那是行水客常用的引煞线” |
| R-31 | 拒绝痛觉循环 | 生理痛觉感官随动作推进递进，禁止同一个伤痛跨段反复巡检打卡 | “砂粒往发白的脚掌肉里磨”跨段循环打卡 |
| R-32 | 避免说明堆砌 | 旁白最多给一个必要事实，不连续堆放多层因果推断 | “大概是……又有……才一直没有……”多层堆砌 |
| R-33 | 拒绝伪精确 | 数量与尺度使用自然感官与生活化观察，避免机械测绘数据 | “每隔七步敲碎一层薄冰”、“北偏东七度”、“长约七尺” |

| R-36 | 拒绝套路瞳孔 | 严禁条件反射式眼睛模板与翻译腔排比 | “瞳孔放大/骤缩”，“没有回答/没有接话，只……” |

### 第1章派生检查

- “没”用于人物口语可以保留；叙述句默认使用“没有”。
- 不机械套用“淡淡开口”。先判断人物是克制、疲惫、敷衍还是轻蔑，再选动作和语气。
- 叶辰的反击台词要有目标和压力，但不能每次都写成预告式狠话。
- 叶灵儿的情绪变化必须经过刺激、生理反应、决定三个环节，不因一句安慰立刻转喜。
- 群体场面拆给两到三个具体人物或具体声音，不写所有人同时震惊、沉默或变色。

### 第3章派生检查

- 群像背景不自动补第二层旁观动作，一句有效议论足以建立压力时立即收住。
- 叶辰的判断不得快于物证；没有足够证据时使用“不清楚、暂时无法确定”等信息边界表达。
- 正文叙述保留“开放、完整的话、引入”等完整搭配；人物对白可以更口语。
- 打斗动作检查动词与目标的空间关系，例如布条或燃物“插进”石缝，玄力“引入”经脉。
- 伤势必须说明受伤位置和肉体后果，后文继续体现疼痛、失血或行动限制。
- **旁白不越权**：旁白只写可观察的物理事实和角色行为，不替读者下价值判断（"敷衍""实在不值当"）、不做情绪总结（"没了不耐"）、不剧透心理决定（"心里已经有了决定"）。
- **对比句式清零**：禁止"X未必能……叶辰却太熟悉"类能力展示对比框架，让判断直接跟在感官后面。
- **说明文解释限量**：旁白对异常现象最多给一个解释理由，不连续堆放三个因果推断。
- **单句独立段合并**：对话中的短句如果不构成节奏关键停顿（如战斗前的"砍后腿！"），应并入上下文段落。

## 六、按错误类型汇总

### 6.1 物理逻辑与词语搭配

- 声音使用“传来、传出、响起”，慎用“漏出、飘出、砸下”等实体动作。
- 动作必须有身体或环境支点，不能为了画面感违反常识。
- 量词、名词和动词要能自然搭配，避开“一抹弧度”式拼接。

### 6.2 汉语节奏

- 双音节动词保持完整，如“颤抖、传出、存在”。
- 不为了短促连续省略谓语、宾语或必要虚词。
- 爆点可以收短，常规叙述保持自然长短句交替。

### 6.3 情绪与动作

- 动作已经表达情绪时，不在句尾再解释一次。
- 人物反应必须符合刚发生的事，禁止无理由转悲为喜。
- 优先写手指、呼吸、站姿、停顿和视线落点，少写抽象情绪标签。

### 6.4 对话与人物身份

- 每句重要台词都应体现人物当下诉求：反击、试探、隐瞒、控制或安慰。
- 叶辰可以克制，但不能软弱无力；强硬台词也必须建立在他掌握的信息或筹码上。
- 同一角色的口吻应稳定，不能为了推进剧情突然说出作者说明式台词。

### 6.5 去AI味

- 禁止否定式煽情：“不是X，是Y”“不是不想，而是不能”。
- 禁止统一群体反应：“所有人都愣住了”“全场死寂”。
- 删除烂俗比喻、重复修饰和刻意空间化表达。
- 避免连续使用“淡淡、平静、轻轻”等万能状态词。

### 6.6 比喻使用标准

**核心公式：好比喻 = 具体感官 + 情境绑定 + 服务动作 + 信息增量**

判断一个比喻是否保留，用"删除测试"：删掉比喻后句子信息量是否明显下降？如果下降，是有效比喻；如果不降反清，是装饰性比喻。

#### 好比喻三原则（满足至少两项即可保留）

**原则一：感官具体化**——比喻必须唤起具体的触觉/视觉/听觉/痛觉，不能用抽象概念比抽象概念。

| 好例（取自《逆天邪神》） | 为什么好 |
|---|---|
| 小手雪白娇嫩，却如铁箍一般死死抓着他的手腕 | "铁箍"唤起具体的触觉——硬、紧、挣不脱，读者能感受到手腕被捏疼的感觉 |
| 凌压竟如万重山岳般沉重 | "万重山岳"把无形的压力转化为可感知的重量，且"山岳"与角色名/场景呼应 |
| 烈千洪的手掌如触电般从玄碑上移开 | "触电"是具体的生理反应，读者能想象手指弹开的瞬间 |
| 温玉般的小手 | "温玉"唤起具体的触觉——温润、光滑 |
| 苍雪般的头发 | "苍雪"唤起具体的视觉——苍白、如雪 |

**原则二：情境绑定**——比喻必须和当前场景/人物身份/动作逻辑紧密关联，不能脱离上下文独立存在。

| 好例（取自《逆天邪神》） | 为什么好 |
|---|---|
| 如一块牛皮糖般粘在萧澈身上 | "牛皮糖"绑定的是缠人、甩不掉的情境，和人物关系匹配 |
| 如一只受惊的小兔子般向后跳开 | "受惊的小兔子"绑定的是女性角色受惊后跳开的动作，画面贴合 |
| 如云一般纯净，水一般清澈 | 呼应"云澈"的名字，比喻与人物身份绑定 |
| 如天空冷月般只可见而不可近触 | 绑定夏倾月的高冷气质和不可接近的距离感 |

**原则三：服务动作**——比喻必须推动动作或情绪进展，不能停在原地做静态标签。

| 好例（取自《逆天邪神》） | 为什么好 |
|---|---|
| 如铁箍一般死死抓着 | "铁箍"服务的是"死死抓着"这个动作的力度，删掉比喻力度感消失 |
| 闪电般的收回 | "闪电"服务的是"收回"这个动作的速度，删掉比喻速度感消失 |
| 如一只受惊的小兔子般向后跳开 | "受惊的小兔子"服务的是"跳开"这个动作，删掉比喻画面感消失 |
| 如丈量好的一般，在完全相同的刹那落于战场之外 | "丈量好"服务的是"精准 timing"这个动作信息，删掉比喻会丢失"精确同步"的含义 |

**原则四：信息增量**——删除比喻后，句子的信息量必须明显下降。

| 好例 | 为什么好 |
|---|---|
| 如一块牛皮糖般粘在萧澈身上 | 删掉"牛皮糖"就失去"粘得极紧、甩不掉"的信息 |
| 如铁箍一般死死抓着 | 删掉"铁箍"就失去"抓得极紧、挣不脱"的信息 |
| 如一只受惊的小兔子般向后跳开 | 删掉"小兔子"就失去"受惊后弹跳"的画面感 |

#### 比喻词阈值

- 比喻词（仿佛/宛如/犹如/好似/像是/如/般）：每章 ≤ 2 处
- 但符合"好比喻三原则"中至少两项的比喻，可适当放宽至 3-4 处/章
### 6.7 数量词使用标准

**核心原则：一股/一丝/一缕/一种 等数量词允许使用，但必须服务于准确表达，不能做无信息量的装饰前缀。**

#### 允许使用的场景

| 场景 | 示例 | 为什么允许 |
|---|---|---|
| 修真术语/功法描写 | 一缕真元、一丝神识、一股玄力、一道灵气 | 修真体系需要量化修炼能量的形态，是设定语言的一部分 |
| 量化必要 | 一道金光自眉心透出、一丝血腥味从风中传来 | 需要明确"量"的多少来传递信息（极淡/极弱/一闪而过） |
| 感官绑定 | 一股灼热毒素沿着经脉蔓延 | "一股"和"灼热毒素"绑定，描述的是可感知的具体物质 |

#### 禁止使用的场景

| 场景 | 坏例 | 改法 |
|---|---|---|
| 装饰性前缀 | 一股深不可测的气息 | 删除"一股"，直接写"气息深不可测" |
| 情绪标签前缀 | 眼中闪过一丝贪婪 | 删除"一丝"，写"眼中闪过贪婪" |
| 抽象概念前缀 | 一种与年龄不符的深沉 | 删除"一种"，写"流转着与年龄不符的深沉" |
| 堆砌使用 | 一股极淡的松脂气息 | 删除"一股"，写"松脂气息极淡" |
| 重复使用 | 同章出现3处以上"一丝/一股" | 分散处理，大部分删除，仅保留修真术语场景 |

#### 数量词阈值

- 装饰性数量词（"一丝/一股/一种/一缕 + 抽象形容词 + 的"）：每章 ≤ 2 处
- 修真术语数量词（"一缕真元/一丝神识"等）：不限，但同章不重复同一搭配
- 判断标准：删掉数量词后，句子的信息量是否下降？不降则删。

| C01-U19 | 反派刻画停留在外观 | 叶天仅靠白色劲装、护手和直白问话表现敌意 | 在台词语气、语气词、用词和有目的的小动作中体现轻蔑、控场与利益立场 | 反派感不能靠作者贴标签或服装承担；对白和动作既要表现性格，也要服务其压缩三房资源、逼叶辰退考的目标。 |
| C01-U20 | 工整推理范式 | “不是顾念同族，而是……把人打醒，再逼着按印，比闹出一条人命容易交代。” | “名额还挂在原主名下。少了那枚指印，大长老一脉拿不走。” | 禁止把人物念头写成“不是A，而是B；做C，再做D，比E更好”的完整论证。只保留当前感知真正触发的一两步判断，允许省略、倒装和断续。 |
| C01-U21 | 运功链条含混 | “元气只走出少许便散入血肉，继续强行引动只会……” | “元气落进气海→断脉针扎般抽痛→游走寸余→溃散于肌体→人物停功” | 玄力运行必须有明确起点、路径、距离、失败表现和身体后果；先把现象写清，再由人物作出判断，不能用抽象结果替代过程。 |
| C01-U22 | 静物对称陈列 | “正面刻着……边角缺了……背面沾着……” | 让身份牌随“塞到面前、落在干草上翻面、露出湿墨、认出缺角”等动作逐步显露 | 物品描写不能按正面、侧面、背面整齐盘点。视角人物只在使用、递交、翻看或取证时注意当前有用的细节。 |
| C01-U23 | 紧急对白次序失真 | 叶灵儿先完整回答手腕伤势，再说明考核将结束 | 先塞身份牌、催叶辰赴考；被问到手腕后只随口答一句，立即回到时限与损失 | 人物在赶时间、救人或逃命时先处理最急目标。次要问题的回答允许打断、略答和转回主线，禁止规整的一问一答。 |
| C01-U24 | 百科式设定注入 | 一段依次解释考核三步、资源分配、弃考后果和按印例外 | 柴房只交代第三遍钟、两块灵石和试炼名额；验碑与抽签规则到现场再出现 | 制度解释按触发点拆开。每次只给当前动作所需的信息，不把流程、对象、资源、后果和例外一次写成词条。 |
| C01-U25 | 完整因果心理模板 | “本想让她留下，免得被卷入；看见红痕，又把话咽回去。” | 直接写叶辰起身、叶灵儿架住他的手臂 | 不把“初衷→顾虑→触发→改变决定”完整排列。动作能够呈现选择时，删去作者代为整理的心理因果链。 |
| C01-U26 | 对称利弊推导 | “叶辰若坚持便……；叶辰若退便……” | 只写叶天查看伤处、摩挲护腕及带有威胁的台词 | 不用两组对称假设把反派打算全部讲透。保留可观察的算计痕迹，让读者自行补足收益与风险。 |
| C01-U27 | 谈判流程过度规整 | “指出问题→提出记录要求→对方解释→请求第三方封存” | 加入讥讽、抢签、打断和刑堂直接介入 | 角色可以理智，但冲突不能写成无情绪的标准申诉流程。让身份、脾气和现场动作打乱对话节拍，同时保留真实筹码。 |
| C01-U28 | 证据结论过快 | “阴寒药性已经留在经脉里至少三年。” | “青黑出现→人物心里一沉→旧伤寒意再次出现→怀疑三年前比试另有手段” | 先写迹象和人物反应，再给与证据强度相符的暂时判断。单次血色异常不能直接证明毒物来源、持续年限或下毒者。 |

派生规则：

- 写“以前的某人总会如何”前，必须能指出正文、人物卡或当前记忆中的依据；没有依据就删除，不用虚构习惯制造身份反差。
- 观察、触摸、移动和封存物证时，动作必须符合人物能力与调查目标。聪明人物不能为了画面感主动破坏证据。
- 亲近人物的对白优先保留语气、抱怨和立场强度。只要符合关系与情境，不把“哼、嘛、本来、绝对、就是”当作冗余词统一删除。
- “皱眉”等直接反应可以使用，但必须由刚刚出现的异常、风险或冲突触发，不作为万能过渡动作。
- 制度名词第一次影响人物选择时，立即回答“指谁、包含什么、如何执行、为何触发、损失什么”；不要把解释拖到场景后半段。
- 上条只要求交代足以改变当前选择的部分，不要求一次讲完制度。流程细节应在登记、验碑、抽签、判罚等触发点分别出现。
- 删除不能改变画面、关系、信息或行动的身体状态句和时间转场句。已经由动作证明的事实不再旁白复述。
- “X却Y”不是默认高级句式。两侧没有认知冲突，或反差不影响后文时，直接写动作或删除整句。
- 人物性格优先进入说话方式：语气词、称谓、句式长短、用词强弱、是否抢话；小动作只在能改变台词含义时使用。
- 比喻不作一刀切禁用。落笔前检查准确性、必要性、视角适配和信息增量，任一项不成立就改为直接陈述。
- 内心推理默认采用“现象→反应→一层判断”，不补齐完整论证。尤其禁用“不是A而是B；做C再做D；比E更好”和成对“若A则B、若C则D”。
- 思绪允许省略和断续，但动作、玄力、伤势与证据链必须清楚。去掉工整不等于牺牲可读性。
- 紧急场景先说最急的事；物品随动作显露；结论不得超过证据实际能证明的范围。
