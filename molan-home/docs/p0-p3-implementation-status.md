- P0：旧 SQLite 迁移脚本移至 `scripts/sqlite-migration/`，原 npm 命令保留。没有运行实际迁移。PureJs 兼容库打开前拒绝 SQLite 二进制和损坏 JSON，避免把旧库覆盖为空库。
- P0：生成任务原生 JSON adapter 已接入显式 `MOLAN_GENERATION_STORE=json`，保存任务、阶段、事件与租约，启动先恢复再监听，取消清理等待异步释放租约。旧任务不会自动迁移；章节提交仍使用既有仓储，提交中断没有真实匹配回执则等待作者确认。
- P0：文风档案保存、读取与版本历史已提供 JSON / PG 原生异步 adapter；本地通过 `MOLAN_STYLE_STORE=json` 显式接入，PG 直接使用已有 RLS 事务。风格审查和记忆上下文从同一仓储读版本，请求体不能伪造权威档案。关闭生命周期等待全部仓储与兼容数据库句柄，失败保留非零退出状态。
- P1：认证、管理、Skill、生成、知识、拆书、项目路由按模块注册并注入处理器；小说读取、创建、保存、软删除、恢复处理器与认证限流服务已抽离，保留 CAS 与权限行为。生产启动没有 PG 配置时直接失败。生产依赖与功能审计覆盖新增模块目录。
- P2：生成调用已接入确定性场景机制召回、债务窗口、到期债务强制保留、模型预算与完整渲染提示核算；编译清单可重放。旧的无分类机制资料保守保留，不借缺少标签删除全部规则。
- P3：规范的 19 个评分维度 A/B CLI、版本绑定、证据状态、0.03 归一化退化阈值、既有安全门禁、候选配置核验与报告查看页。`quality:promote` 只有门禁通过才原子写入明确指定候选文件的晋级凭据，当前 Golden 为 metadata_only，禁止晋级；没有付费模型调用或真实质量增益声明。
